# Thesis-VoNR

## Description

Repository for VoNR and 5G SA implementation. Based on the open-source libraries available on the internet, the VoNR service will be implemented in 5G SA systems and tested in a real environment with phones.

## Roadmap

- SIP Server to setup calls (**Done**).
- SIP Server to send SMS (*In progress*).
- Install IMS and HSS.
- Connect IMS/HSS with 5G SA System.
- Calling Test.
